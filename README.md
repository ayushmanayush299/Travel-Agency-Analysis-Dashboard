# Travel-Agency-Analysis-Dashboard
Data analysis project using Power BI and Excel to visualize travel agency customer behavior, booking trends, and revenue insights.

## Project Overview
This project is an interactive Power BI dashboard created to analyze travel agency customer data.  
The dashboard helps understand customer travel behavior, popular destinations, booking trends, and revenue insights.

## Objectives
- Analyze customer travel patterns
- Identify popular travel destinations
- Track revenue generated from bookings
- Understand age group preferences
- Support business decision-making with data insights

## Dataset Information
The dataset contains customer travel records with the following fields:
- Customer ID
- Age
- Age Group
- Destination
- Booking Date
- Travel Type
- Revenue

## Key Performance Indicators (KPIs)
- Total Customers
- Total Bookings
- Total Revenue
- Average Trip Cost

## Dashboard Visualizations
The dashboard includes the following visuals:
- Age Group vs Destination
- Revenue by Destination
- Monthly Booking Trend
- Travel Type Distribution
- Popular Destinations

## Key Insights
- Younger customers prefer beach destinations.
- Families tend to prefer international trips.
- International travel generates higher revenue.

## Tools Used
- Power BI
- Microsoft Excel
